# 第二课堂｜抖音内容分析台

这是一个零依赖的单文件中文抖音作品数据分析工具。

## 使用方法

1. 下载或打开 `index.html` （可在电脑 Edge / Chrome 中打开）。
2. 点击「下载 CSV 模板」，填写真实作品数据并保存为 UTF-8 CSV。
3. 导入文件，查看作品数量、总播放量、平均播放量、互动率、分类表现以及作品排行。
4. 使用「导出当前数据」定期备份。

## 数据字段

`发布时间,标题,类型,播放量,点赞,评论,收藏,分享`

类型建议使用：口播、今日寄语、数据图、每日一题。相同发布日期及标题的数据再次导入时会覆盖旧记录。

## 隐私与限制

- 不要求抖音账号密码，也不会自动获取抖音后台数据。
- 数据保存在你当前浏览器的 localStorage，不会自动上传至 GitHub。
- 不同设备或不同浏览器之间不会自动同步；清除浏览器存储可能导致数据丢失，请及时导出 CSV 备份。
- 互动率 =（点赞 + 评论 + 收藏 + 分享）/ 播放量；不是官方后台的完播率或转粉率。
- 仓库目前为公开仓库，请勿提交包含个人资料、账号密码或敏感业务信息的 CSV。
